ICU Early Warning System

A machine-learning early-warning tool that predicts ICU patient deterioration / mortality risk from early clinical indicators — heart rate, blood pressure, age, and optional lab values — and explains each prediction to the clinician through a bedside decision-support dashboard.

What this project does

ICU patients can deteriorate hours before it is obvious on a routine chart review. This project builds a risk-scoring pipeline — from raw vital-sign data to a trained gradient-boosting model — and wraps it in a clinical dashboard that flags at-risk patients, ranks them by urgency, and explains why the model raised the alarm for each individual patient.
